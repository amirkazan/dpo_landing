# Космические системы — программа МФТИ

Адаптивный статический лендинг по экспорту Canva «Современные подходы к разработке систем ДЗЗ и космической связи». HTML, CSS и JavaScript без сборки и сторонних зависимостей. Исходные PNG сохранены без изменений. Фотографии и видео из `originals/` обработаны в `assets/`: фото — WebP, записи экрана «Интеграла» — зацикленные GIF (`ffmpeg`, 10 fps, 560 px, `-loop 0`).

## Запуск

Откройте `index.html` в браузере или выполните из корня проекта:

```sh
python3 -m http.server 8080
```

Адрес: http://localhost:8080/. Остановка сервера — Ctrl+C. Для публикации достаточно загрузить `index.html`, `styles.css`, `app.js`, `links.js` и `assets/` на статический хостинг. Исходные PNG и тесты публиковать не требуется.

## Навигация

- «Да, я впервые» → `#about`: описание курса, программа и результаты.
- «Нет, я уже знаком с курсом» → `#materials`: шесть кнопок материалов в одном разделе.
- Номера страниц старой инструкции заменены смысловыми разделами: в PNG нет однозначного порядка страниц.
- Меню адаптируется к мобильному экрану. Якорные переходы работают нативно; текст страницы доступен без JavaScript.

## UX/UI-слой

Поверх базы Canva добавлены интерфейсные улучшения:

- **Навигация**: подсветка активного раздела в меню (IntersectionObserver + `aria-current`), тень шапки при скролле, плавающая кнопка «наверх» после 600 px прокрутки.
- **Появление блоков**: плавный fade-up при скролле через `data-reveal`; включается только при работающем JS (класс `.js` на `<html>`), без JS контент виден сразу. При `prefers-reduced-motion` анимации отключены.
- **Пауза GIF**: у каждой зацикленной GIF кнопка паузы/запуска (стеклянный круг, иконки на чистом CSS). Пауза подменяет GIF статичным постером (`assets/*-poster.webp`, первый кадр исходного видео). При `prefers-reduced-motion` анимации стартуют на паузе. Кнопка с `aria-pressed` и `aria-label`.
- **Иерархия**: кикеры-номера разделов («01 — Чему вы научитесь»…), primary/secondary кнопки в hero, нумерация пилюль материалов 01–06.
- **Диалог**: анимация появления, закрытие по кнопке, Escape и клику по подложке.

## Дизайн

Вёрстка повторяет стилистику макетов Canva: чёрные секции чередуются с сине-градиентными и светлыми лентами; огромные тонкие заголовки; моноширинные подписи в верхнем регистре; кнопки и карточки — градиентные «пилюли» и глассморфизм; декоративные «блобы» и рукописные SVG-линии. Структура секций повторяет макеты: hero с карточкой курса (Services.png), баннер «Современное прикладное образование» со спутниками (Home.png), «Чему вы научитесь?» с пилюлями уровней, «Что именно будем изучать?» с пилюлей «144 часа • 5 модулей • 22 занятия» (Contact.png), лента «Как проходит обучение?» и секция «Интеграл» с GIF (FAQs.png), карточки миссии, объединённая секция «Финал программы» + «Что вы получите?», стек пилюль материалов (Services.png) и финальный призыв с регистрацией (6.png, Contact (2).png). Шрифты — локальные Manrope и JetBrains Mono (`assets/fonts/`, woff2 с кириллицей, `font-display:swap`), без внешних CDN.

## Адреса, которые нужно предоставить перед публикацией

В экспорте нет действующих URL материалов и QR-кодов. В `links.js` задана
только ссылка регистрации (Яндекс Формы), остальные пока равны `null`:

| Ключ | Назначение |
| --- | --- |
| `registration` | ✅ Регистрация на курс — forms.yandex.ru/cloud/6a21a51a90290294e1e12c7a |
| `recordings` | Видеозаписи лекций |
| `assignments` | Задания по курсу |
| `guides` | Методические материалы |
| `syllabus` | Полная программа курса |
| `presentation` | Презентация курса |
| `assessment` | Правила итоговой аттестации |
| `integral` | Программный комплекс «Интеграл» |

Замените `null` соответствующим абсолютным HTTP(S)-адресом в кавычках. После перезагрузки все кнопки этого ресурса автоматически будут открывать адрес в новой вкладке с `rel="noopener noreferrer"`. Незаполненные ссылки открывают уведомление, а не фиктивную форму регистрации. Проверяется формат URL, не доступность внешнего сервиса.

Если появятся QR-коды, их изображения можно разместить внутри ссылки `a[data-resource]` с соответствующим ключом — они будут работать как остальные кнопки. Сейчас выдуманные QR-коды не добавлены.

Сведения о программе (144 часа, 5 модулей, 22 занятия, форматы обучения и результаты) перенесены из макетов. Перед публикацией организаторам нужно подтвердить их актуальность.

## Файлы

- `index.html` — тексты, секции и семантическая разметка.
- `styles.css` — оформление и адаптивные стили.
- `links.js` — единый конфиг внешних адресов.
- `app.js` — ссылки, диалог и мобильное меню.
- `assets/` — локальные иллюстрации и favicon; сайт не загружает внешние шрифты, аналитику или библиотеки.
  - `classroom.webp` — фото занятия (hero), из скриншота `originals/2026-08-31 21.45.01.jpg` с обрезкой интерфейса телефона.
  - `satellite-blue.webp`, `satellite-gold.webp` — спутники из `originals/` для блока «Современное прикладное образование».
  - `lab-laptop.webp` — ноутбук с «Интегралом» (`originals/2026-08-31 21.45.06.jpg`, обрезаны чёрные поля) в блоке «Чему вы научитесь».
  - `integral-ballistics.gif`, `integral-coverage.gif`, `integral-swaths.gif` — зацикленные GIF из трёх записей экрана `originals/*.mov` для секции «Интеграл».
  - `integral-*-poster.webp` — первые кадры видео для режима паузы GIF.
  - `space-grid.webp` — декоративная 3D-сетка из макета Canva (блок контактов).
  - `logo-kadry.webp` — официальный логотип федерального проекта «Кадры для космоса» (белый на прозрачном), скачан с официального сайта кадрыдлякосмоса.рф.
  - `logo-fakt.webp` — логотип ФАКТ (знак + словесный знак), собран горизонтально из официального логотипа с сайта fakt.mipt.ru.
  - `programma-kursa.pdf`, `programma-kursa.docx` — программа курса: содержание свёрстано прямо в модальном окне, DOCX скачивается кнопкой, PDF — запасной вариант для ссылок без JS.
- `originals/` — исходные фото и видео; не публикуются.
- `tests.mjs` — тесты без зависимостей.

## Проверки

Node.js 18+:

```sh
node --test tests.mjs   # контракт ссылок, диалогов, меню (20 тестов, без зависимостей)
node visual-qa.mjs      # визуальный QA в Chromium: 5 ширин, скриншоты в qa/
```

`visual-qa.mjs` проверяет переполнение, загрузку изображений, якоря, диалог,
меню, паузу GIF, reveal-анимации, кнопку «наверх» и ошибки JS; скриншоты
складывает в `qa/` (в `.gitignore`). Пути к playwright-core и Chromium
резолвятся автоматически или через переменные `QA_PLAYWRIGHT` / `QA_CHROME`.

Правила для правок UI — в `DESIGN.md` (дизайн-система из макетов Canva)
и `AGENTS.md` (чек-лист для AI-агентов).
