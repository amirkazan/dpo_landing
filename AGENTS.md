# AGENTS.md — правила для AI-агентов в этом репозитории

Ты работаешь над продакшн-лендингом курса МФТИ, а не над generic AI-демо.

## Перед любыми правками UI

1. Прочитай `DESIGN.md` — это зафиксированная дизайн-система, извлечённая из
   макетов Canva заказчика. Используй только её токены и компоненты.
2. Градиенты, глассморфизм, пилюли и «блобы» здесь разрешены — они из Canva.
   Но запрещено выдумывать новые варианты сверх `DESIGN.md`.
3. Сохраняй существующее поведение, доступность и работу без JS.

## Жёсткие правила

- Внешние ссылки — только через `links.js` (`window.COURSE_LINKS`). Не вставляй
  выдуманные URL, QR-коды и формы регистрации: при `null` показывается диалог.
- `a[data-resource]` всегда с `href="#link-notice"` и `data-label`; якоря
  `#about`/`#materials` — обычные ссылки без `data-resource` (инструкция заказчика).
- Медиа — локальные из `assets/`; источники в `originals/` не трогай и не публикуй.
- Не подключай внешние шрифты, CDN, трекеры. Без сборки и npm-зависимостей.
- Не скрывай контент средствами только JS. `prefers-reduced-motion` обязателен.

## Цикл проверки (обязателен перед отчётом)

1. `node --test tests.mjs`
2. `node visual-qa.mjs` — при дефектах исправь и прогони снова.
3. Открой скриншоты из `qa/`, сравни с `DESIGN.md` и макетами Canva,
   перечисли конкретные расхождения. Не пиши «выглядит хорошо» без скриншотов.

## Стиль коммуникации с заказчиком

- Русский язык, коротко и по делу.
- Ссылки и материалы курса предоставляет заказчик — напомни, если их нет в `links.js`.
